为什么是它

游戏内可编程红石

每个方块 6 个面都能读 / 写红石信号。写计算逻辑，接红石线，立刻驱动整片电路——加法器、比较器、计数器都能做。

Java 实时编译

想写完整的类？放一个 .java，游戏内调用 javac 实时编译（需 JDK 启动 MC）。

定时热重载

保存文件后约 1 秒自动检测到变动并重载；右键方块也能强制刷新并查看运行状态。

目前只有26.2版本支持​

维护26.2（开发构建）单条 Fabric 构建线。​

双标签页归位

创造模式里，代码方块同时出现在「红石」标签页与「管理员 / 命令方块」标签页，和命令方块怼一起。

多窗口分屏

开任意多个悬浮小窗，拖动、缩放、置顶随便调；小窗纯监视不抢键鼠，主窗照常操作。显示源任选：主画面实时镜像、HUD 特写、F3 文字、快照定格。

主画面实时镜像

把主窗口的游戏世界 3D 画面实时复刻进小窗，走哪看哪——挂后台盯工程、多机位解说都方便。

暂停界面复刻

按 ESC 的暂停菜单、箱子等容器界面、任意模组 GUI，全都跟着主画面复刻进小窗，照常显示不缺角。

HUD / F3 特写小窗

HUD 特写走元素级白名单，只保留快捷栏、血量、饥饿、护甲、经验条；F3 调试文字也能提取成独立小窗。

三步上手

拿方块 → 写程序 → 接红石

  1. 01

    拿到方块

    创造模式 → 物品栏「红石」标签页（或管理员标签页）→ 找到「代码方块」，放到世界里。

  2. 02

    写程序

    右键方块，聊天栏显示它的 id（10 位十六进制）。到程序目录新建 CB_<id>.java写逻辑。（默认无需手动创建，放下就自动创建）

  3. 03

    接红石

    方块 6 面自动发出红石。把红石源接它的输入面、红石线接它的输出面，保存即热重载运行。

DSL 速览

几行就能跑的代码片段

通道 0=下 1=上 2=北 3=南 4=西 5=东；cin(c) 读、cout(c,v) 写，强度自动限制在 0–15。

可选附加模组

ecj 编译环境（给 JRE 用户）

官方启动器默认用 JRE 跑 MC，没有 javac，游戏内编译 .java 会失败。装这个独立小 mod（内置 Eclipse JDT Core / ecj 编译器）后，JRE 环境下主模组会自动调用它编译 Java——无需把 MC 改成 JDK 启动，也无需自己预编译 .class。可装可不装。

CodeBlock ECJ Compiler

companion mod
  • 作用：JRE 环境下提供完整 Java 编译能力
  • 依赖：需先装主模组 CodeBlock Mod
  • 版本：随主模组支持 1.21.11 / 26.2

✅ 已发布 v0.1.0：jar 已构建并上传，JRE 用户把它丢进 mods/ 即可在游戏内编译 Java，无需安装完整 JDK。
